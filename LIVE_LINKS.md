## 🔄 UPDATE YOUR WEBSITE

### **Method 1: Using Git (Recommended)**

1. **Clone the repository**
   ```bash
   git clone https://github.com/Kaaviyaa-809/Toyworld.git
   cd Toyworld
   ```

2. **Edit index.html** in your favorite editor

3. **Push to GitHub**
   ```bash
   git add index.html
   git commit -m "Update website"
   git push origin main
   ```

   - No manual deployment needed

## 🆘 TROUBLESHOOTING

### **Link Shows 404 or Blank Page**
**Solution**: Try one of the alternative links provided above

### **Styles look broken**
**Solution**: Hard refresh (Ctrl+Shift+Delete or Cmd+Shift+R)

### **Changes not showing**
**Solution**: 
1. Clear browser cache
2. Wait 30 seconds for Netlify to rebuild
3. Try in incognito/private mode

### **Want to use GitHub Pages instead of Netlify**
Visit: https://github.com/Kaaviyaa-809/Toyworld/settings/pages
- Set source to "main" branch
- Set path to "/" (root)
- Wait 1-2 minutes
- URL: https://kaaviyaa-809.github.io/Toyworld/
